0:00 · The hook

Two lambdas.
One language.

# Ruby lambda — strict arity
->(x) { x }.call(1, 2)  # ArgumentError

# AWS Lambda — keyword handler
def lambda_handler(event:, context:)
  # ...
end

Both are contracts about arguments. Only one runs on a t-shirt company's monolith.

2:00–5:00. AppSignal and Ruby docs acknowledge the naming collision. AWS handler docs recommend keyword args. Quick audience vote: who knew Ruby had lambda? who knew Custom Ink runs Rails on Lambda?

18:00 · The other fork

Jets Mega Mode:
Puma in /tmp.

Ruby on Jets can spawn a Rack subprocess inside Lambda. Rails boots on writable /tmp because the filesystem is otherwise read-only. +1–3 s cold overhead.

Lamby removes the inner server. Mega Mode embeds one. Both shipped real apps.

18:00–21:00. Jets docs call it “most pragmatic” for migration. Mention prewarming cron (“poor man’s provisioned concurrency”) only if asked — cuts time.
21:00 · Compile budget

Enable YJIT
after boot.

# 37signals pattern — also for Lambda
ENV["RUBYOPT"] = "--yjit-disable --yjit-exec-mem-size=192"
# ... Rails boot ...
RubyVM::YJIT.enable

Ruby 4.0 defaults YJIT ON — but Init phase is not where you want to compile Rails.

21:00–24:00. Basecamp ~18% faster; ~98% code in YJIT on 3.3+. Zenn benchmark: YJIT ON +~60ms cold, −3ms warm on small handler. X-Ray Init phase = cold-start truth.
24:00 · Numbers

Cold starts
are a product feature.

1–3s+containerized Rails without tuning
1792MB — Lamby vCPU sweet spot

Scale to zero ≠ free latency. Provisioned concurrency buys warmth; Jets prewarm cron buys cheaper warmth.

24:00–27:00. Do not promise sub-100ms p99 without budget. Container lazy-loading helps large images but first touch still costs.
27:00 · 60-second grid

Use it when…

  • Spiky traffic and bounded HTTP + queue shape.
  • You can pop hot paths out first (Custom Ink pattern).
  • IaC + containers are already in your toolchain.
Internal APIs, webhooks, catalog/image edges. Steady high QPS → Kamal/Fargate often wins on sanity and bill.
27:00 · Stay honest

Skip it when…

  • WebSockets, >30 s work, or cheap cold p99 on a budget.
  • “Just deploy Rails” is the whole goal.
  • 2014-style big-bang microservices is the motivation.

Serverless is a scaling model — not an apology for a monolith.

Audiences trust skip cases. Custom Ink failed microservices before Lambda succeeded on extracted pieces.
