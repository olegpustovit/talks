## About the talk

### Title *

WebAssembly and JavaScript

### Short description *

WebAssembly did not appear out of nowhere. Its story runs through JavaScript's
number model, Emscripten, and the unusual `|0` coercions generated by asm.js.
This talk follows that history, then shows what happens when data crosses
between JavaScript and C++: integers, strings, typed arrays, pointers, copies,
and ownership. A small image-processing demo explains when WebAssembly helps,
what Embind hides, and how to avoid stale memory views and excessive boundary
calls.
